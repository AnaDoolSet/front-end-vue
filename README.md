# Data Table

A small front end project in Vue3 to display two data table exctracted from a CSV. You need to install and run the [back end of this project](https://github.com/AnaDoolSet/parser-spring-boot) as well for it to work correctly.
Free assets from [JkHuger](https://uiverse.io/JkHuger/dangerous-dolphin-42), [Anasmalik57](https://uiverse.io/Anasmalik57/great-grasshopper-29) and [jaykdoe](https://uiverse.io/jaykdoe/tasty-dragon-12).
Dataset from [datagouv.fr](https://www.data.gouv.fr/datasets/donnees-temps-reel-de-mesure-des-concentrations-de-polluants-atmospheriques-reglementes-1).


## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
cd .\data-table\ 
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```

### Run Unit Tests with [Vitest](https://vitest.dev/)

```sh
npm run test:unit
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```
